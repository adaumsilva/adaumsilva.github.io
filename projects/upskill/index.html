Upskill

Personalized learning, in the flow of work.

PRODUCT GALLERY01 / 05

Upskill dashboard overview

Overview

An enterprise AI learning platform that integrates with Slack and Google Workspace to identify skill gaps and generate personalized learning interventions.

How it works

  • A dual-model pipeline uses Llama 4 for analysis and GPT-5 for learning content.
  • A FastAPI backend supports artifact ingestion and asynchronous analysis, with PostgreSQL for storage.
  • A Next.js dashboard presents skill insights. The platform is deployed on Microsoft Azure Foundry.
